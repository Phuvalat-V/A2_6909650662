03 What I Built

I developed my A1 Learning Portfolio into a responsive website using HTML, CSS, and Bootstrap 5. The website includes an About Me section and a portfolio section to showcase my work and experiences.

I used Bootstrap Grid to organize the content into different columns depending on the screen size. This makes the website easier to use on both desktop and mobile devices.

04 How I Built It

  1. I started by using my previous A1 website as the foundation for this project.
  2. I added Bootstrap 5 to improve the layout and make the website responsive.
  3. I used Bootstrap containers, rows, and columns to organize the About Me and Portfolio sections.
  4. I customized the colors, fonts, and spacing using CSS.
  5. I used Git and GitHub to track changes and GitHub Issues to organize my tasks.
  6. I tested the website on different screen sizes to check its layout and readability.

05 Reflections

This assignment helped me understand how to use Bootstrap to create responsive web layouts. I also learned how GitHub Issues and commits can help organize the development process.

One of the challenges was adjusting my original CSS to work properly with Bootstrap. I had to test different layouts and make changes to improve the appearance of the website.

In the future, I would like to improve my web design skills and learn more about building interactive websites.
