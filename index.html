02 What I Built

I built a single-page website with a header, main content, and footer. Using CSS, I styled the page to make it visually appealing.

This website contains information about me, my interests, how I built it and reflections.

To view this website, the browser acts as the client. But there is no connection to a server because the files are loaded directly from my computer rather than from a web server.

03 How I Built It

  1. I started by using VS Code as my text editor.
  2. I used HTML to structure the content of the page, including headings, paragraphs, and sections. I then applied CSS to style the elements, such as changing colors, fonts, and layout.
  3. I also divided the page into sections such as About Me, What I Built, and How I Built It, and Reflections with each section containing relevant information.
  4. I used CSS selectors to target specific elements and apply styles to them.
  5. I also used Git for version control to track changes.
  6. Finally, I tested the website in the browsers to ensure compatibility.
